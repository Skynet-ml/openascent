# OpenAscent

OpenAscent is an open standard for optimization runs.
You define a metric. A runner changes your code and measures each change with that metric.

This repository will hold the reference Python package of the standard.

## Status

Release 0.0.1 is a placeholder. It reserves the package name and has no function yet.
The first working release will add the component call, the result rules and the `ascent` command.
